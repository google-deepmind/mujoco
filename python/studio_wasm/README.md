# MuJoCo Studio Web Viewer Browser Client (`mujoco-studio-wasm`)

[![PyPI Python Version][pypi-versions-badge]][pypi]
[![PyPI version][pypi-badge]][pypi]

[pypi-versions-badge]: https://img.shields.io/pypi/pyversions/mujoco-studio-wasm
[pypi-badge]: https://badge.fury.io/py/mujoco-studio-wasm.svg
[pypi]: https://pypi.org/project/mujoco-studio-wasm/

This package contains the precompiled WebAssembly browser client (`web_client`)
for the [MuJoCo](https://mujoco.org) Studio Web Viewer
([GitHub](https://github.com/google-deepmind/mujoco)).

It is installed automatically as a dependency of `mujoco-studio` (and `mujoco`):

```sh
pip install mujoco
```
